**Token Bucket Algorithm - Key Concepts:**
- A "bucket" holds tokens (permits)
- Tokens are added at a fixed rate (refill rate)
- The bucket has a maximum capacity (burst size)
- Each request consumes one (or more) tokens
- If tokens are available, the request is allowed; otherwise, it's denied (or queued)
- This allows bursts up to the bucket capacity while enforcing an average rate

- `capacity` (or `bucket_size`): maximum tokens the bucket can hold
