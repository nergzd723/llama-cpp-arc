**Token Bucket Algorithm:**
- A "bucket" holds tokens (up to a maximum capacity)
- Tokens are added at a fixed rate (refill rate)
- Each request consumes one (or more) tokens
- If there aren't enough tokens, the request is denied (or queued)
- The bucket has a maximum capacity (burst size)

Key parameters:
- Capacity (max tokens in bucket)
- Refill rate (tokens per second)
- Current token count
- Last refill timestamp

The beauty of token bucket:
- Allows bursts up to capacity
- Enforces average rate over time
- Simple to implement
- Used in networking (traffic shaping), API rate limiting, etc.
