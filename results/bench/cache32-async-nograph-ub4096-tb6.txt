# Token Bucket Rate Limiter: Detailed Explanation & Implementation

## How a Token Bucket Rate Limiter Works

### Core Concept

The **token bucket** algorithm is a widely used rate-limiting mechanism that controls the rate at which operations (e.g., API requests, network packets) are allowed to proceed. It works by maintaining a "bucket" that holds a finite number of **tokens**, each representing permission to perform one operation.

### Key Parameters

| Parameter | Description |
|-----------|-------------|
| **Capacity** (`max_tokens`) | Maximum number of tokens the bucket can hold. This defines the maximum burst size. |
| **Refill Rate** (`refill_rate`) | Number of tokens added to the bucket per second. This defines the sustained rate limit. |
| **Current Tokens** (`tokens`) | The current number of tokens available in the bucket. |
| **Last Refill Time** (`last_refill`) | Timestamp of when tokens were last added, used to calculate how many tokens to add on the next request. |
